# WhatsApp Sender Pro 🚀
**أداة متقدمة واحترافية لإرسال رسائل واتساب المجمّعة وإدارة الحملات بذكاء**

تطبيق ويب عصري ومتجاوب بالكامل (Mobile-First Responsive Web Application) صُمم خصيصاً لتسهيل إرسال الرسائل الفردية والمجمعة عبر واتساب، مع دعم لصق مئات الأرقام من ملفات Excel، وإدارة القوالب، وتخصيص الرسائل التلقائي بالأسماء.

---

## ✨ المميزات الرئيسية

- 📱 **متجاوب 100% مع الهواتف والشاشات المختلفة:**
  - عرض جدولي احترافي للشاشات الكبيرة وأجهزة الكمبيوتر.
  - بطاقات ذكية مخصصة لشاشات الجوال بدون أي انكسار أو سكرول عرضي مزعج.
- ⚡ **إدخال ولصق مجمّع ذكي (Bulk Import):**
  - لصق قائمة أرقام كاملة مباشرة من Excel أو المفكرة.
  - دعم مختلف الصيغ (أرقام فقط، اسم ورقم، أرقام بين أقواس، إلخ).
  - إمكانية رفع ملفات `CSV` أو `TXT` مباشرة.
  - كشف واستبعاد الأرقام المكررة تلقائياً.
- 🌐 **معالج كود الدولة التلقائي:**
  - تحويل الأرقام المحلية (مثل 010... في مصر أو 05... في السعودية) إلى صيغ دولية صالحة لواتساب تلقائياً.
- 🏷️ **تخصيص الرسائل بالمتغيرات الديناميكية:**
  - دعم إدراج متغير `{الاسم}` ليتم استبداله باسم العميل في كل محادثة بشكل آلي.
- 💬 **قوالب رسائل جاهزة ومعاينة حية:**
  - قوالب جاهزة (ترحيب، عروض ترويجية، تذكير بمواعيد، استبيان).
  - محاكاة دقيقة لفقاعة محادثة واتساب لرؤية مظهر الرسالة قبل إرسالها.
- 📊 **لوحة إحصائيات حية وشريط تقدم:**
  - تتبع فوري: إجمالي الأرقام، تم الإرسال، قيد الانتظار، ونسبة الإنجاز المئوية.
- 🚀 **مساعد طابور الإرسال (Queue Assistant):**
  - إرسال متسلسل منظم بضغطة زر لتجنب حظر الأرقام وتسريع إنجاز الحملات.
- 📥 **تصدير النتائج:**
  - تصدير قائمة الأرقام مع أوقات وحالات الإرسال إلى ملف `CSV` بترميز UTF-8 المتوافق مع اللغة العربية في Excel.
- 🌙 **الوضع الليلي والنهاري (Dark / Light Mode):**
  - مظهر مريح للعينين مع تبديل سلس واحتفاظ بالاختيار.

## 🛠️ كيفية التشغيل

لا يتطلب أي خوادم أو تثبيت مكتبات معقدة! فقط افتح ملف `index.html` في أي متصفح ويب (Chrome, Edge, Safari, Firefox) على جهاز الكمبيوتر أو الهاتف.
