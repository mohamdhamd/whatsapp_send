# بَلِّغْ 🚀
**إرسال رسائل وتس**

> قال رسول الله ﷺ: *"بَلِّغُوا عَنِّي وَلَوْ آيَةً"*

تطبيق ويب عصري وسريع ومتجاوب بالكامل (Mobile-First Responsive Web App) مخصص لإرسال رسائل وتس المجمّعة وإدارة المجموعات والملاحظات وتخصيص الرسائل.

---

## ✨ المميزات الرئيسية

- 🗂️ **إدارة المجموعات المتعددة (Multi-Groups):**
  - تقسيم جهات الاتصال إلى مجموعات مختلفة (عملاء VIP، حملات ترويجية، قوائم متابعة).
  - تبديل سلس مع عزل تام للأرقام والإحصائيات لكل مجموعة.
- ✏️ **تعديل بيانات العملاء والملاحظات (Contact Notes):**
  - تدوين ملاحظات خاصة بكل عميل تظهر مباشرة في البطاقات وتدخل ضمن البحث الفوري.
  - إمكانية تعديل الاسم، الرقم، والمجموعة في أي وقت.
- ⏸️ **تعليق واستبعاد الأرقام (Pause / Suspend):**
  - استبعاد أي رقم من الإرسال التلقائي بضغطة زر مع تجاوزه آلياً أثناء الحملة.
- 📱 **متجاوب 100% مع الهواتف والشاشات المختلفة:**
  - عرض جدولي احترافي للشاشات الكبيرة وأجهزة الكمبيوتر.
  - بطاقات ذكية مخصصة لشاشات الجوال بدون أي انكسار أو سكرول عرضي مزعج.
- ⚡ **إدخال ولصق مجمّع ذكي (Bulk Import):**
  - لصق قائمة أرقام كاملة مباشرة من Excel أو المفكرة.
  - دعم مختلف الصيغ مع كود الدولة التلقائي واستبعاد المكرر.
- 🏷️ **تخصيص الرسائل بالمتغيرات الديناميكية والقوالب الجاهزة:**
  - دعم متغير `{الاسم}` لاستبداله باسم العميل في كل محادثة تلقائياً.
- 📊 **لوحة إحصائيات حية ومساعد الإرسال المتتابع (Queue Assistant):**
  - تتبع فوري لحالات الإرسال، مع شريط تقدم وإرسال متسلسل سريع.
- 📥 **تصدير النتائج إلى ملف CSV** متوافق مع اللغة العربية في Excel.
- 🌙 **الوضع الليلي والنهاري (Dark / Light Mode):**
  - مظهر مريح للعينين مع تبديل سلس.

---

## 🛠️ كيفية التشغيل

لا يتطلب أي خوادم أو تثبيت مكتبات معقدة! فقط افتح ملف `index.html` في أي متصفح ويب (Chrome, Edge, Safari, Firefox) على جهاز الكمبيوتر أو الهاتف.
